# Personal portfolio

Two static portfolio page versions:

- `ai-generated-page.html` — the AI-generated design, with its styles and menu script in the matching folders.
- `me-designed-page.html` — a dark, blue-bubble introduction and compact Experience/Goals list inspired by the supplied reference image. Experience entries are academic: URJC and UNNC.

## Preview locally

Open either HTML file directly in a browser, or serve this folder with any static file server. No dependencies or build step are required. The manually designed page uses native HTML links, so it needs no JavaScript.

## Publish with GitHub Pages

Commit and push this folder to the repository, then enable GitHub Pages in the repository settings. Open the published URL with `/personal-portfolio/ai-generated-page.html` or `/personal-portfolio/me-designed-page.html` appended.
